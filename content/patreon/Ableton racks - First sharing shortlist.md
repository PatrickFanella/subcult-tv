# Which Ableton rack should I share first?

## Post copy

Alongside LOW and Origami, I've been looking through my Ableton library for tools worth sharing here.

I have a few effects racks that could make useful downloads. They need another pass before I package them. The saved versions have their device chains in place, but the macro controls still need mapping and testing.

The first candidate is a dub and breakbeat delay rack. It combines Filter Delay and Echo with filtering, saturation, output control, and a limiter. I want to give it a small set of controls for delay throws and feedback, with ranges that are useful without becoming unmanageable.

The other candidate is a transition rack with filtering, Beat Repeat, Echo, reverb, pitch shifting, and saturation. The goal is to make it easy to take a part out of the way, stretch a transition, or bring the next section in without opening several devices.

I'd rather start with one finished rack and a short walkthrough than upload a folder of presets with unexplained controls. The download would include the Live requirements, what each macro does, and a demo using material I can include with it.

Which would you use first: the dub delay or the transition rack?

### Packaging checklist

- [ ] Save separate release-candidate copies, leaving the library originals intact.
- [ ] Verify authorship and any redistribution conditions for included content.
- [ ] Name and map the macros; test minimum, maximum, and bypass behavior.
- [ ] Test in a blank Live set, save, close, and reopen.
- [ ] Check missing files, external plugins, and exact Live version and edition requirements.
- [ ] Exclude the Cracker vocal, Freddie Gibbs acapella, Ja'afar Hassan sample, and third-party sample banks from the rack download.
- [ ] Make a short demo with self-recorded or otherwise redistributable material.
- [ ] Include a README and explicit terms for the original rack work, without claiming ownership of Ableton devices or other people's content.
- [ ] Attach the finished package before changing this preview into a download announcement.
