# Flash / Websites as experiences

Motion, sound and staged navigation as the central composition of a website.

## Source observations

The museum has Flash galleries for the 90s and early, middle and late 00s, including 2Advanced and Requiem for a Dream.

[Source collection or timeline](https://www.webdesignmuseum.org/flash-websites) · [Gallery to explore](https://www.webdesignmuseum.org/flash-websites)

## Design direction

These design notes and exercises are SUBCULT interpretations, rather than specifications supplied by the museum.

Use transitions to explain movement between scenes. Give visitors control over sound and a direct path to the main content.

| Element | Suggested treatment |
| --- | --- |
| Typography | Short scene labels; readable supporting text |
| Layout | Staged sequence; persistent orientation |
| Color | Restrained palette; action-led transitions |

## Where to use it

An interactive release artwork or short exhibition.

## Studio exercise

Sketch three connected scenes for a release. Provide a static reading path and check the sequence with reduced motion enabled.
