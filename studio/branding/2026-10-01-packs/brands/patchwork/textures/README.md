# Patchwork texture assets

Paper and fabric tiles are original editable SVGs. Paper grain uses black at 2.5% opacity. The weave uses white at 3.5% opacity. Keep these opacity limits when placing texture beneath text; the audit checks those bounds.

The website sample uses CSS background images for texture and `patch-stitches.js` for responsive SVG stitching. Stitches are 2.4 px wide, with varying lengths, gaps and small tilts. A dashed CSS border remains available when JavaScript is disabled. The sewing assets in `../decorative/` are optional original vector accents; they are decorative in the sample and hidden from assistive technology.

These are local brand assets. Applying them to the live website is separate work.
