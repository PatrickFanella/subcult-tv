Popups
------
Bindings are generated from the merged registry:

- Default: /tmp/subcult-current-review-20261105/terminal/tmux-popups/popups.tsv
- Local:   /tmp/subcult-current-review-20261105/terminal/render-env/config/tmux-popups/popups.local.tsv

Local rows override default rows with the same id. Reload tmux to regenerate.

Direct binds
------------
Prefix + Enter       Quick Menu (configurable: @tmux-popups-menu-key)
Prefix + R        reload tmux config (configurable: @tmux-popups-reload-key)

Prefix + C-h     popup help         help           deps:tmux                   ok
Prefix + T       shell              shell          deps:shell                  ok
Prefix + C-b     tmux keys          keys           deps:tmux                   ok

Quick Menu keys: Prefix + Enter, then key
----------------------------------------------
H       popup help         help           deps:tmux                   ok
Enter   shell              shell          deps:shell                  ok
N       notes              notes          deps:editor                 ok

b       tmux keys          keys           deps:tmux                   ok
v       vscode here        configurable: @tmux-popups-vscode-command
R       reload tmux        source /tmp/subcult-current-review-20261105/terminal/render-env/home/.tmux.conf
q       exit menu
