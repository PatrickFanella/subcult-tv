# Font licences

The WOFF2 files in this directory are the Latin subsets served by Google Fonts,
self-hosted so the app does not depend on a third-party font request.

| Files | Family | Licence |
| --- | --- | --- |
| `barlow-*.woff2` | Barlow, Copyright 2017 The Barlow Project Authors | SIL Open Font License 1.1 |
| `barlow-condensed-*.woff2` | Barlow Condensed, Copyright 2017 The Barlow Project Authors | SIL Open Font License 1.1 |
| `ibm-plex-mono-*.woff2` | IBM Plex Mono, Copyright 2017 IBM Corp., Reserved Font Name "Plex" | SIL Open Font License 1.1 |

The full licence text is in `OFL.txt`.

Landing pages additionally self-host Fraunces, Public Sans, Newsreader, Inter
Tight, and Space Mono from Google Fonts. Newsreader and Inter Tight are the
variable Latin subsets. Their full SIL Open Font License texts are included as
`fraunces-OFL.txt`, `publicsans-OFL.txt`, `newsreader-OFL.txt`,
`intertight-OFL.txt`, and `spacemono-OFL.txt`.

The Kork landing uses Archivo Black (`archivo-black-400.ttf`, Copyright 2017 The
Archivo Black Project Authors), copied unchanged from the subcult-studio Kork
brand pack (`branding/library/fonts/ArchivoBlack-Regular.ttf`). Its SIL
Open Font License text is `archivoblack-OFL.txt`.
