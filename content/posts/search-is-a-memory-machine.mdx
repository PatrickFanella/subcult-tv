# Search is a memory machine: clips, transcripts, fingerprints, and the fight against amnesia

Months after a livestream, someone remembers a sentence but not the hour it was spoken. The popular clip starts two lines too late. Reposts name no source. Platform search returns whatever is recent.

The file still exists. Its origin has become hard to find, and that is one way culture gets lost. Deletion is the obvious way. Loss of context is quieter: the quote detaches from the speaker, the sound from its maker, the clip from the conversation around it.

Search tools can reconnect some of those records. Several SUBCULT projects work on this at different scales and stages.

HasanAra is live. It is a searchable archive of HasanAbi broadcast transcripts, built on Rekolekt, our software for timestamped recording archives. Each result links back to the timestamp it came from, so a long broadcast becomes something a person can inspect and cite.

That does not make a transcript authoritative. The transcripts are automatic. Speech recognition makes mistakes, and diarization can assign a line to the wrong speaker. The recording remains the source, and the timestamp is what makes checking it possible.

clpr, also live, organizes Twitch clips for discovery and sharing. Curation can preserve who made a clip, where it came from, and why a community kept it. Those details are the difference between a record and a detached fragment.

Sound travels through edits with even less context. Soundhash is an incubating audio fingerprinting project for matching clips across social platforms. Its promise is narrow: give a searcher a possible route back through copies. A fingerprint cannot settle authorship or consent. A match is evidence to examine, not a verdict.

The zine handles another part of the same problem. An essay in an archive has an address and neighbors, and readers can return to it long after its announcement has gone down a timeline.

## The mundane part

Much archival work is mundane. When something matters, save the way back to it:

- Add timestamps.
- Keep source URLs.
- Store enough metadata to verify a claim.
- Export records before an API changes.
- Write down why an artifact mattered.

Platforms have weak incentives to preserve that context. Their search products commonly favor current activity and engagement, so reposts and reactions can outrank the source once attention gathers around them.

Our own tools need limits too. Search ranking encodes choices. Archives can reproduce surveillance. Collecting every available artifact is neither necessary nor safe, so retention, consent, access, and provenance belong in the design.

Useful search returns enough context for a person to judge the result: who published it and when, which recording contains it, whether the file has changed, and what the surrounding minutes say.

No single database will hold a culture's memory. We can still keep better records of the work entrusted to us, and make those records portable when a host changes its terms.
