# Minimalist — selection guide

Working criteria: Select for a reduced interface vocabulary, deliberate negative space, restrained color and a clear content hierarchy. Minimalism can support dense content; it does not require empty pages.

Start with: [Mike Matas](../../examples/mike-matas/GUIDE.md), [Everlane](../../examples/everlane/GUIDE.md), [teenage engineering](../../examples/teenage-engineering/GUIDE.md).

## From reference to design system

Write rules for spacing, imagery and hierarchy instead of only removing decoration. Distinguish sparse marketing pages from the fuller controls required by commerce or product use.

Record the component vocabulary, typography roles, semantic color mapping, spacing, image/illustration rules and motion fallback. Treat single screenshots as composition evidence; do not infer a global scale or complete interaction system from them.

This is a selected research set, not an exhaustive history of the style. The examples include strong matches, hybrids and comparison candidates so differences remain visible. Follow each guide's evidence notes before adapting a reference.
