# Posting best practices

Research checked October 1, 2026. Apply with [[Social Posting Automation Plan]], [[Timely Posting Plan]] and [[Social Media Library]]. Platform requirements, observational studies and local editorial choices are different evidence. None establishes guaranteed reach or a universal posting hour.

## Platform guidance and requirements

X recommends a recognizable voice, audience-relevant topics, conversational posts and suitable photos/videos. It also recommends attending to mentions and conversations. We retain deliberate human participation windows rather than automated replies. [X's presence guide](https://business.x.com/content/dam/business-twitter/resources/x-downloadable-guides/build-your-presence-on-x-one-sheet.pdf).

X supports descriptive image alt text, up to 1,000 characters. Describe the important visible content rather than repeating the caption. For video, plan readable captions and a useful first frame; image alt text is not a video caption mechanism. [X accessibility guidance](https://help.x.com/en/using-x/picture-descriptions).

Instagram's professional dashboard offers general and account-specific guidance across creation, engagement, reach, monetization and policies. We have not inspected these accounts' dashboards; use their actual recommendations when connected rather than treating a generic list as personalized advice. Meta also reports continuing emphasis on original content. Adapt our own assets and commentary; attribution alone does not grant reuse permission. [Meta's creator guidance](https://about.fb.com/news/2024/10/best-practices-education-hub-creators-instagram/), [Meta's January 2026 update](https://about.fb.com/news/2026/01/2026-ai-drives-performance/).

X prohibits automated trend-topic posting and duplicative or substantially similar posts across operated accounts. The timely lane remains human-selected/manual for trend-driven publication, with distinct routing and copy. [X automation rules](https://help.x.com/en/rules-and-policies/x-automation).

## Research that suggests experiments

Buffer's 2026 format analysis reports stronger median engagement for Instagram carousels, while its separate reach analysis favors Reels for discovery. These are observational Buffer-published samples, with differing periods and metrics; they do not prove a format causes better results on our accounts. Test a short original demonstration versus a small explanatory carousel when Instagram is connected. Judge reach and useful engagement separately. [Buffer's format research](https://buffer.com/resources/data-best-content-format-social-media/).

No platform-independent optimum time or volume was established by this research. Keep the user-confirmed cadence. Start with current Chicago windows and compare similar posts over several weeks before changing one window or format. A single popular post is insufficient evidence.

## Local editorial choices

- Lead with one concrete observation, useful action or question. Remove throat-clearing, inflated promises and forced sales pitches. Use a call to action only when there is a clear next step.
- Patrick carries interpretation and left-political commentary; SUBCULT carries products and independent culture; CLPR stays focused on clips and Twitch context. Select one destination for a discovered conversation.
- Do not require an image for every post. Use a real capture to demonstrate a workflow, an original illustration to convey a concept, or text-only for a concise point or quote. Keep product access/readiness boundaries in the copy where they affect the reader.
- No engagement bait or irrelevant trending hashtags. Zero hashtags is a valid default; add a specific useful tag only when it helps identify the topic. This is an editorial choice, not a claimed algorithm penalty.
- Check original reporting, quotations and surrounding context before political or current-event commentary. Generated illustrations must not simulate documentary news scenes, real-person endorsements or actual product screens.
- Write alt text for every image. For multiple images, review each description in the final composer. Plan captions/transcripts for recordings, readable text at phone size, clear contrast and safe margins. Publication must confirm accessibility fields survived the actual provider path.
- Keep generation prompts, source URLs, creator/license information and file hashes in the media library. Credit-required assets need their credit in the final package. Do not assume an article image or Twitch clip is cleared merely because it is public.

## Formats and delivery checks

Use PNG/JPEG stills as conservative starting formats. Square images work as a shared starting point; 4:5 is an optional Instagram portrait master and 9:16 is an optional Story/Reel master. These are local production defaults, not mandatory platform dimensions. Preserve original masters and create separate variants when needed; check current API/composer behavior before dispatch.

Buffer currently documents up to four images on X and ten on Instagram through its integration, regardless of higher native limits. It documents 5 MB static images for X, 8 MB for Instagram, and an Instagram 3:4–1.91:1 range in its image guide. Another Instagram guide still says 4:5–1.91:1. Because those pages differ, square/4:5 are conservative choices; verify 3:4 in the actual channel before relying on it. [Buffer attachments](https://support.buffer.com/en-us/articles/attaching-images-videos-and-other-media-to-your-posts-eudySt0TnS), [Buffer image specifications](https://support.buffer.com/en-us/articles/ideal-image-sizes-and-formats-for-your-buffer-posts-JxHNGZFvf9), [Buffer Instagram guide](https://support.buffer.com/en-us/articles/using-instagram-with-buffer-YSjg2dXFV8).

Keep URLs in the post when needed: an attached image is not a clickable website card. X creates its own link preview, so a Buffer preview does not prove the final X card. Buffer's Instagram integration does not currently add trending music; choose rights-cleared audio or a deliberate native workflow. Recheck the destination and credits after upload; upload is separate from publication. [Buffer attachment behavior](https://support.buffer.com/en-us/articles/attaching-images-videos-and-other-media-to-your-posts-eudySt0TnS), [Instagram integration](https://support.buffer.com/en-us/articles/using-instagram-with-buffer-YSjg2dXFV8).

## Weekly review

Compare account, topic, format, local window and asset ID against actual published URLs. Record reach/impressions, link clicks, substantive replies, saves/shares and follows only when available; name the metric's definition and denominator before calculating rates. Draft count and generated media count measure preparation, not audience response. Recommend one small keep/change/stop decision. No analytics means no performance claim.

The installed weekly and timely runners read this guide, emit a structured media choice, validate library references and write pending production requests. They do not upload media, change approval state or publish. Image generation currently happens through the interactive built-in tool; unattended paid image API generation is not installed.
