# Tadooer product web assets

`tadooer_product_assets.py` generates these files from the Tadooer pack artwork. Text is outlined. `favicon.svg`, `apple-touch-icon.png`, `icon-512.png` and `icon-maskable-512.png` go in `apps/web/public/` and the web manifest. `og.png` has no URL because the planner has no public domain. Its headline is sample copy that the owner has not reviewed. Copy the files into the product. To change one, regenerate it here; do not edit the copies.
