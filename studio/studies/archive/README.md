# Retired design sources

This directory groups earlier brand reviews, the superseded Patrick Signal system, logo studies, legacy profile SVGs and differing imported review-worktree originals. They are source/reference material, excluded from the authenticated production export. Current brand packs are in `../library/`; Patrick’s selected source is in `../patrick/`.

All Studio SVG bytes were retained during the repository cleanup, including owner-edited marks and layouts. Obsolete legacy profile PNG/JPEG/HTML renders and unused Signal banner generators were removed. The original files remain recoverable at the baseline recorded in `../../../docs/cleanup-receipt.json`.

Historical pages and generators describe their original systems. They are not approval for production use or instructions to replace current packs. Rebuild current artwork through the active generators.
