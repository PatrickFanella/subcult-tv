## Design direction

These design notes and exercises are SUBCULT interpretations, rather than specifications supplied by the museum.

Use a reading column, descriptive headings and an explicit index. Let linked titles carry navigation.

| Element | Suggested treatment |
| --- | --- |
| Typography | Readable serif body; plain headings |
| Layout | One reading column; linked contents |
| Color | Neutral ground; a clear link color |

## Where to use it

A research archive or reading room.

## Studio exercise

Make a reading-room page for SUBCULT essays. Check whether someone can find an author, topic and source from the index.
