## Design direction

These design notes and exercises are SUBCULT interpretations, rather than specifications supplied by the museum.

Design a hierarchy that survives changes in width. Establish type, spacing and interaction rules before adding visual variants.

| Element | Suggested treatment |
| --- | --- |
| Typography | Deliberate type scale; readable measure |
| Layout | Content-driven breakpoints; flexible media |
| Color | Consistent action, status and emphasis roles |

## Where to use it

A product library or publication used on phones and desktops.

## Studio exercise

Compare a release-detail page at phone and desktop widths. Keep title, artist, play action and credits in a sensible order at both sizes.
