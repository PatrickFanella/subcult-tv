# Patrick__eff portrait library

Selected by Patrick on October 4, 2026 for the current Patch branding. This library contains the 47 remaining portraits from the selected collection; the outdoor professional headshot is reserved as the GitHub selection. Original photographs and previous edits remain in Pictures.

[Browse the portrait gallery](index.html). The five earlier picks and three mirror-selfie edit sets are kept in separate folders. Each mirror-selfie set contains seven square avatars and seven taller portraits. The first cropped versions retain original settings; the studio and indoor-wall versions contain phone removal and generated backgrounds. Fine details in AI-assisted edits can differ from the source photographs.

Use the purple-lit portrait for creative profiles and the black-and-white photograph for artist or editorial bios. The black-shirt portrait with glasses is the strongest neutral alternative; the hoodie peace sign and crown photos suit informal posts. Keep photographs in their saved colors and use Patch typography, charcoal panels and lavender rules around them. The selected PF logo remains available for music artwork and creative accounts.

All image copies are verified byte-for-byte. manifest.json records source paths, edit types and SHA-256 hashes. The selected pack receives this library from the authoritative `brand-tools/patrick/portraits/` directory when rebuilt. Adding the files to Studio does not publish all of them on a public profile.
