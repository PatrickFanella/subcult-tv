Install

from a committed, reviewed checkout · Python 3 on Linux
  1. 01 
    python scripts/validate.py
PYTHONDONTWRITEBYTECODE=1 python -m unittest discover -s tests -v
    Validation needs PyYAML. The catalog and capability map must be complete before anything is installed.
  2. 02 
    python scripts/install.py plan > /tmp/patstack-plan.json
    Read-only. Review the changed destinations, ownership and retired names before applying.
  3. 03 
    python scripts/install.py apply --through 1
python scripts/install.py apply --resume <run-path> --through 2
python scripts/install.py apply --resume <run-path> --through 3
    Three batches, one journal. Each writes verified original backups under the run directory.
  4. 04 
    python scripts/install.py verify
python scripts/install.py rollback --run <run-path>
    Verify compares hashes, modes and symlink targets. Rollback restores only that run's destinations and preserves later edits.
