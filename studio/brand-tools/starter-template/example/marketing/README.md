# Marketing starter

Use this packet with the brand starter's visual layouts. It supplies product context, claim evidence, copy, a demo brief, a 30-day plan, and reusable drafting prompts. These are templates with unresolved fields, not approved campaign copy.

1. Complete [context.md](context.md) with the product's audience, supported scope, current offer, voice, claim sources, and desired action.
2. Draft [packet.md](packet.md) from that context. Select the channels and sections that fit the project.
3. Use [prompts.md](prompts.md) for focused drafting and review. Supply the completed context with each prompt.
4. Pair the copy with real product captures and the generated brand layouts. Record rights, captions, and final alt text.
5. Verify the selected product journey, links, claims, and commercial terms. Remove unresolved public placeholders before publication.

The brand bootstrap copies this directory into the new pack as `marketing/`. It fills the product name, canonical destination, and token reference from `brand.json`; it leaves audience research, evidence, pricing, and campaign decisions for you to complete. A supplied tagline does not establish that its promise is supported.

Use the new pack's `GUIDE.md`, `tokens.json`, and `source-register.json` alongside this packet. Keep the finished packet in its product repository and link it from Studio when relevant. The documents can also be copied independently into a project's `docs/marketing/`; update local asset references for that layout.

This selected companion snapshot comes from the original Subcult marketing template in `codex-skills`; [provenance.json](provenance.json) records its revision and source hashes. Update from that source deliberately and review Studio-specific guidance together. Full imported Okara research remains in the separate private marketing-reference repository.

Drafting the packet does not publish, contact anyone, purchase placements, or create a recurring schedule. The private Studio text library exposes these starter documents for reading and individual download.

For product-specific draft examples, see the source packets for [clpr](https://git.subcult.tv/subculture-collective/clpr/src/commit/2ed46bfcfb7f103a51ccf48ae25113fe4150bed9/docs/marketing/README.md) and [Subsets](https://git.subcult.tv/subculture-collective/subsets/src/commit/45aafb43846a0fa206c9bb26bed0b417274e95f8/docs/marketing/README.md). Each product repository owns its facts and campaign copy.
