# CSS / Layout pioneers, 2002–2005

Editorial structure and visual identity built through styles applied to page content.

## Source observations

The gallery includes Wired News 2002, CSS Zen Garden 2003 and A List Apart 2003, starting points for comparing layout and typography.

[Source collection or timeline](https://www.webdesignmuseum.org/css-layout-pioneers) · [Gallery to explore](https://www.webdesignmuseum.org/css-layout-pioneers)

## Design direction

These design notes and exercises are SUBCULT interpretations, rather than specifications supplied by the museum.

Keep content structure stable and vary presentation. Use hierarchy, spacing and alignment to give a publication its voice.

| Element | Suggested treatment |
| --- | --- |
| Typography | Distinct title style; steady body rhythm |
| Layout | Consistent article and navigation alignment |
| Color | Small accents for links and sections |

## Where to use it

A publication theme or family of artist pages.

## Studio exercise

Create two treatments for the same artist biography and release list. Check content order and link labels in both.
