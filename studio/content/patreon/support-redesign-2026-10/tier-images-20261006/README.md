# Patreon tier banners

Five upload-ready PNGs, generated October 6, 2026, for Supporter, Backer, Patron, Groceries and Rent. Each export is exactly 460 × 200 pixels.

The images follow the selected [SUBCULT Culture / poster press guide](../../../../brands/subcult/GUIDE.md): purple, dark ink, acid green, warm off-white and textured poster artwork. Each banner names its tier without prices or reward claims.

Use the `*-460x200.png` files for Patreon uploads. `contact-sheet.png` previews all five at their final size. Original generated images are preserved in `sources/`.

`manifest.json` records the built-in image generator, exact prompts, source paths, export dimensions and SHA-256 hashes. The exports were resized with ImageMagick using `-resize '460x200!' -strip`; the generated sources already use approximately the same aspect ratio.

The banners have been checked for lettering, dimensions and legibility at the export size. Review their crops in the Patreon editor when uploading. Creating these files does not publish or upload them.

PNG files use Git LFS. The ZIP download is local packaging and is excluded from Git.
