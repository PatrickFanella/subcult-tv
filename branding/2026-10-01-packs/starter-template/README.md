# Brand starter template

Edit `brand.json`, then create a new directory:

```sh
python3 bootstrap.py brand.json /path/to/new-brand-pack --render
```

Python 3 creates the editable SVG layouts, tokens, source register and asset manifest. `--render` also needs rsvg-convert and produces PNGs with the included fonts. The generator refuses to overwrite an existing directory, rejects invalid colors and requires ordinary text/background contrast of at least 4.5:1.

The kit supplies logo/mark placeholders; banners; square, landscape, story, quote and release layouts; a screenshot frame; video title, thumbnail, end-card and transparent lower-third layouts. It includes Space Grotesk, Public Sans and JetBrains Mono with their OFL licenses. The initials are temporary artwork, not a finished identity.

Choose an audience and a concrete promise. Set the palette and typography roles. Create an original mark, then check it at 32 pixels and define its clear space. Refine the layouts for the new brand instead of copying another product’s signature motif. Keep the six existing product identities separate.

Record source and publication rights for photos, screenshots, quotations and footage. Replace placeholder copy, verify claims and write alt text before publication. Use the eight brand guides as examples of a completed system.
