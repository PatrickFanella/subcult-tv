# Generic Skills: Open Manual

Generic Skills is a collection of portable procedures for coding agents. Its
identity reads as a technical manual: explicit labels, large type, warm paper,
and a compact index corner. The G-shaped manual is an original vector mark,
separate from Subsets' selected-tile identity.

## Selection and scope

The owner requested creation and application of repository branding. The agent
compared A / Open Manual, B / Tool Socket, and C / Library Index using the same
name, description, small mark, and SKILL.md card. A was selected for its readable
small mark and relation to a portable instruction file. B resembled a hardware
utility; C was too close to a document-archive identity. `directions.png` retains
the comparison. This is an agent selection under the publication instruction,
not a recorded owner vote.

This pack covers Gitea repository identity and README artwork. It does not
specify an application UI, campaign, website, or social publishing program.

## Visual rules

Use paper #f3f1e9 and ink #152b35 for the primary composition. The orange indexed
corner (#d6532e) is a graphic accent, not small body text. Muted labels use
#52636a. Display lettering is Space Grotesk Bold; supporting copy is Public Sans;
file labels are JetBrains Mono. Exported SVG lettering is outlined.

Use an 8 px spacing unit and at least 18 units clear around the 128-unit mark.
Use the mark at 24 px or larger. Preserve its corner proportions and open
counter. The monochrome variant uses one ink.

The banner is 1600 x 560 with a 64 px inset. Use the 512 x 512 paper-backed avatar
for repository listings. Body copy describes actual procedures and resources.
The master banner has no skill count, so catalog growth does not stale it.

## References and rights

The Studio Swiss study (`references/2026-10-02-style-research/styles/swiss/GUIDE.md`)
informed shared alignments and compact type hierarchy. It is a dated design
study, not a source of artwork. The mark, index corner, and composition are new.
No third-party imagery or signature logo was copied. Font licenses accompany
the pack. Public exports use an explicit asset selection with source hashes.

## Rebuild

From the repository root, run `python3 studio/brand-tools/repository_identity.py`.
It builds only Generic Skills and the Headcount/Chatty Cat repository extensions.
It requires fontTools, rsvg-convert, and the licensed shared Studio fonts.
