# Brand starter template

Change `brand.json`, then run:

```sh
python3 bootstrap.py brand.json /path/to/a/new-brand-pack
```

The script creates editable SVG layouts for a 1500×500 banner, 1080×1080 square post, 1080×1920 story, 1600×900 landscape post and 512×512 avatar. It refuses to replace an existing output directory. Use short names and taglines, then inspect text fitting in your editor.

Start with the audience, one clear promise and three concrete examples. Choose type and color roles before applying them to formats. Add an original mark, record its source and rights, and test it at 32 pixels. Keep body text readable; use accent colors for emphasis when their contrast allows it.

The current starter is a review example. An approved brand pack should add outlined logo exports, light and dark versions, clear-space rules, minimum sizes, photography guidance, reusable social and video layouts, alt text, a source/rights register and an asset manifest.
