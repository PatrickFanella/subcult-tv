# subcult.tv

> [!abstract] SUBCULT’s public Stage, Transmission surface, and durable archive. It should show what exists, make project state legible, and give every publication a life beyond the feed.

## Definition of success

A visitor can understand what SUBCULT is, inspect current and historical projects, read the archive, and choose a concrete relationship to the work without being misled about ownership, governance, funding, or project readiness.

## Current state

- The site is live at https://subcult.tv.
- It includes projects, zine, About, support, memo, investment, metrics, links, and press-kit surfaces.
- Its strongest visual and verbal identity is already recognizable.
- Several categorical claims drift from the current canon or conflict across pages; [[001 Projects/Works/Social Posts/SUBCULT Marketing/SUBCULT Website Copy|SUBCULT Website Copy]] contains the replacement copy and audit.
- Public GitHub and Gitea catalogs contain more current project evidence than the old vault note represented.

## Page responsibilities

| Page | Job |
|---|---|
| Home | Identity, current signals, and the clearest next actions |
| Projects | Status-aware catalog with evidence and lifecycle distinctions |
| Zine | Durable editorial archive, not an infinite feed |
| About | Worldview, operating commitments, and honest organization shape |
| Support | Sustainability without implying governance rights or guaranteed access |
| Memo | Periodic operational memory: shipped, broken, learned, changed |
| Metrics | Contextual measures with definitions, dates, and limits |
| Press | Canonical descriptions, visual assets, links, and verified facts |
| Partner | Grants, sponsorships, collaborations, services, licensing, or aligned investment under explicit terms |

## Repurposing pattern

1. Publish the durable article or release on subcult.tv.
2. Create a companion note using [[001 Projects/Works/Patreon/Patreon Post Templates|Patreon Post Templates]].
3. Extract platform-specific signals through [[001 Projects/Works/Patreon/Twitter X Promotion|Twitter X Promotion]], [[001 Projects/Works/Patreon/Instagram Promotion|Instagram Promotion]], and [[001 Projects/Works/Patreon/TikTok Promotion|TikTok Promotion]].
4. Link every derivative back to the archived source.
5. Record corrections and status changes on the durable page rather than scattering silent edits across social posts.
