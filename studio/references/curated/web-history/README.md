# Web history references

Eight authored studies follow Web Design Museum's five timeline periods and three focused collections. Period subtitles, design directions and exercises are SUBCULT editorial interpretations. Sources were checked on October 4, 2026. `sources.json` records the links and hashes of the authored Markdown sources.

Edit the Markdown documents and `catalog.json` together, then refresh the authored file hashes in `sources.json`. Paths are relative to `studio/references/`. The private exporter combines catalogs under `curated/*/catalog.json` with the imported catalog. Keeping authored studies separate lets `import_references.py` refresh third-party imports without overwriting them. Duplicate IDs stop the export.

These studies link to exhibits and include no copied museum screenshots. Export and index the private bundle through the existing Studio procedure to make them available in a running environment. They belong in the authenticated reference library.
